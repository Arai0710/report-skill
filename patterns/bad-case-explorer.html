Filterable / expandable / severity-ranked list of low-score rows. Required section for any evaluation or annotation report. This demo uses mock data — replace MOCK_CASES with your real data.

What this demonstrates:
  • Severity-based color tier (red ≥0.6, orange 0.3–0.6, blue <0.3) on the left border
  • Click row header → expand to show all scores, deduction reasons, content blocks
  • Three filters compose (AND logic); slider for severity threshold
  • Empty state when no rows match filters
  • Code-formatted blocks for JSON content (tool calls, API responses)
  • Counter shows filtered/total
