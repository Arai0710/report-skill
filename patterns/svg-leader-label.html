Pattern: Two overlapping lines with non-overlapping labels

Two series with paired data points at every x-tick. The label placement algorithm decides above/below for each label and pushes them apart if they'd collide.

Try the three scenarios:
  • Similar values — A and B are close at most points, forcing the algorithm to spread labels vertically
  • Diverging values — easy case, labels naturally fit
  • Near-boundary — points near top/bottom of plot force labels to flip to the opposite side
Algorithm:
  1. Higher point gets label above, lower point gets label below
  2. If point near top edge → flip its label below (and push the other down if needed)
  3. If point near bottom edge → flip its label above
  4. Final pass: if labels still overlap, force-separate around midpoint
