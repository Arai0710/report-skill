# Data Visualization Report Skill

一个用于将多种结构化数据转换为专业、可交互 HTML 分析报告的 Codex Skill。

它不只是生成图表，还会先检查数据质量、识别指标与维度，再生成带有数据依据的结论、可视化图表和明细表格。

## 主要功能

- 自动分析数据结构、字段类型和数据质量
- 识别指标、维度、时间字段和对比字段
- 生成关键指标卡片、趋势图和分类对比图
- 根据实际数据生成可追溯的文字结论
- 支持筛选、明细查看和异常案例分析
- 默认输出一个便于分享的独立 HTML 报告
- 支持打印和导出，并兼顾不同屏幕尺寸

## 支持的数据

- CSV、TSV 和 Markdown 表格
- Excel 工作簿及多个工作表
- JSON、NDJSON 和嵌套 JSON
- 数据库导出结果
- 评测、标注、问卷、实验、运营、销售和监控数据
- 可以整理为记录与字段的半结构化日志

## 适用场景

- 数据可视化与数据分析
- 周报、月报和管理层汇报
- 趋势分析与分类对比
- 业务看板和运营报告
- 评测报告与标注质量分析
- Bad case、低分案例和异常数据分析

## 使用示例

安装此 Skill 后，可以向 Codex 提出类似请求：

```text
请使用 data-viz-report 分析这份 CSV，并生成一份可交互的 HTML 销售报告。
```

```text
分析这个 Excel 中各个工作表的数据，找出主要趋势、异常项和低分案例。
```

```text
根据这份评测数据制作报告，包含核心指标、模型对比、结论和明细表格。
```

## 安装

下载或克隆本仓库，将仓库文件夹放入 Codex 的 Skills 目录，并确保文件结构如下：

```text
data-viz-report/
├── SKILL.md
├── agents/
├── assets/
├── patterns/
├── references/
└── scripts/
```

安装后，在新的 Codex 会话中通过数据分析、报告、看板、趋势、对比或评测报告等请求触发此 Skill。

## 工作流程

1. 识别分析目标与数据含义
2. 读取、整理并检查输入数据
3. 分析缺失值、重复值、异常值和字段类型
4. 选择合适的指标、图表和报告结构
5. 生成带有数据依据的结论与交互式 HTML 报告
6. 校验数字、筛选功能、页面布局和导出效果

## 输出特点

生成的报告强调结论与证据一致，不会只堆放图表。报告通常包含：

- 数据范围、来源和分析假设
- 核心结论与关键指标
- 主要趋势和分类对比
- 数据质量与分析方法说明
- 可筛选的明细数据
- 适用时提供 Bad case 或异常案例浏览
